# Archived historical & retrospective reports

This directory holds point-in-time reports, certifications, audits, and agent-run
scaffolding that were produced during earlier phases of the ESF Enterprise Platform
build. They are **kept for reference only** and are **not maintained**. Figures,
version strings, and test counts inside them reflect the moment they were written and
may be stale.

For the current, authoritative state of the project always use the living documents at
the repository root:

- **`PROJECT_STATE.md`** — current milestone, status, and verification.
- **`CHANGELOG.md`** — chronological record of changes.
- **`TECHNICAL_DEBT.md`** — outstanding hardening/backlog items.
- **`ROADMAP.md`** — completed and remaining work.

If anything here disagrees with those four files, the root documents win.
