**Дата:** 2026-08-05  
**Юрисдикция:** Кыргызская Республика (решение фаундера)  
**Цель:** Создать инфраструктуру для заключения первого LOI с банком КР под AML-модуль

## Решения

| Параметр | Решение |
|---|---|
| Юрисдикция | КР |
| Форма юрлица | ОсОО (единственный учредитель) |
| Целевой рынок | Банки КР (НБКР-регулируемые) |

| Модель выхода | Бесплатный пилот 90 дней → годовая лицензия |

### 2. Шаблон LOI
Файл: `docs/business/2026-08-05-loi-aml-template-kg.md`

**До отправки:** юридическая проверка, заполнить плейсхолдеры.

| Статья | Сумма |
|---|---|
| Пилот 90 дней | 0 сом (бесплатно) |
| Годовая лицензия | 1 500 000 – 2 500 000 сом/год (~$17K–$28K) |
| Внедрение (разово) | включено в первый год |
| Поддержка 8×5 | включена в лицензию |

---

## Критерии успешности пилота

1. Снижение ложноположительных алертов ≥ 20 %
2. Охват транзакций ≥ 95 %
3. Отчёт НБКР формируется ≤ 30 минут
4. Чек-лист НБКР — PASS
5. Удовлетворённость команды ≥ 4/5

### 4. Trust Pack — Досье соответствия НБКР/ФАТФ
Файл: `docs/business/2026-08-05-trust-pack-nbkr-fatf.html`

- Матрица покрытия: 15 требований (Закон КР №80 / НБКР / ФАТФ R.10–R.27), статус PASS/В пилоте
- Архитектура безопасности: локализация данных, AES-256, TLS 1.3, HSM, хранение 7 лет
- Аудиторный след: HMAC-цепочка → якорение → верификация без доступа к Системе
- Референсный опыт: ESF Platform v1.1.6 + AIOS Core (ACCEPTED)
- FAQ: 6 типичных вопросов прокьюремента/комплаенса

**Отправлять:** после one-pager, перед подписанием LOI, или по запросу CCO.

## Риски

| Риск | Митигация |
|---|---|
| Банк требует действующее юрлицо до разговора | Ускоренная регистрация ОсОО (1 день в ГРС) |
| Procurement требует аудит/ISO | Пилот-формат обходит это — не контракт |
| НБКР меняет требования | Обновления правил включены в лицензию |
| Конкурент с готовым продуктом | Единственный КР-специфичный вендор с открытым аудитным следом |
